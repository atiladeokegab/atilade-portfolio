# Refinery

AI tools modernise your mainframe code. Refinery proves it is safe to deploy.

An AI tool (watsonx Code Assistant, Copilot, Cursor, any LLM) changes a COBOL program. Refinery diffs the original against the change, runs 11 deterministic checks, a semantic engine and a Z3 formal proof, and produces a signed certificate, a regulatory evidence pack and a sign-off workflow that ends with a named human.

It is not a linter and not a test runner. It is a compliance gate that produces things a regulator can inspect.

## Run, Catch, Prove, Explain

- **Run** the original and the change side by side
- **Catch** the changes regulators care about, with the regulation cited
- **Prove** equivalence formally where it holds
- **Explain** it in a certificate a risk officer can sign
